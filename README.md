# 🛒 RetailPulse Analytics

An end-to-end AI-powered Retail Analytics Platform built using the **Online Retail II Dataset**. The project provides intelligent insights for retail businesses through demand forecasting, customer segmentation, churn prediction, inventory optimization, and model monitoring.

---

# Features

- 📈 Hybrid Demand Forecasting (Prophet + LSTM)
- 👥 Customer Segmentation (RFM Analysis)
- ⚠️ Customer Churn Prediction (XGBoost)
- 📦 Inventory Optimization
- 🔬 Data Drift Monitoring
- 🤖 Automated Retraining Pipeline
- ☁️ Streamlit Dashboard

# Dataset

The repository already includes the processed data required to run the Streamlit dashboard.

The complete dataset (including raw and intermediate datasets used for data preprocessing, feature engineering, and model training) is provided separately due to GitHub file size limitations.

**Complete Dataset (Google Drive):**

https://drive.google.com/drive/folders/1bAGQm33bIF37evTbzYGQxPHZ4SDVlzyb?usp=sharing

The additional dataset is only required if you want to:

- Retrain the machine learning models
- Reproduce the complete data preprocessing pipeline
- Execute the Airflow pipeline from scratch

# Installation

## 1. Clone or Download the Repository

Download or clone the repository from GitHub.

---

## 2. Create a Virtual Environment

```bash
python -m venv venv
```

Activate the virtual environment.

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

---

## 3. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4. Run the Application

```bash
streamlit run app/main.py
```
